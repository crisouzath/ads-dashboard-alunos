# Dashboard de Alunos

## 📚 Sobre o Projeto

Este projeto foi desenvolvido como atividade acadêmica do curso de **Análise e Desenvolvimento de Sistemas (ADS)**.  
O objetivo do sistema é fornecer um **dashboard de alunos**, permitindo visualizar, pesquisar e filtrar informações de forma dinâmica e organizada.

No desenvolvimento do projeto, foi implementada toda a lógica em **JavaScript** responsável pelas funcionalidades de:

- Pesquisa de alunos
- Filtros dinâmicos
- Manipulação de dados
- Atualização da interface em tempo real

---

## 🚀 Funcionalidades

- 🎯 Filtros personalizados por nota e turma
- 📋 Listagem dinâmica de alunos
- ⚡ Atualização instantânea dos resultados
- 🎨 Interface organizada e intuitiva
